RESEARCH_RAHI.SYS
Research Project · Rahi

Roommate Compatibility Prediction Using BERT and Ensemble Learning

A Hybrid Approach to Personality Trait Prediction and Compatibility Classification

Gayatri Kamdar · Jigyaasa Science Honors Program · HSNC University, Mumbai
Machine Learning NLP Behavioral Analytics Personality Prediction
GitHub Repository View Application

Overview

The rise of shared accommodation in Mumbai has created a need for better roommate-matching systems. Traditional approaches such as manual surveys, interviews, or random assignment often focus on basic preferences and demographics, while roommate compatibility can also depend on behavioral and lifestyle factors such as sleep schedules, cleanliness, budget, smoking habits, and social preferences.

This research investigates whether structured lifestyle data and unstructured textual descriptions can be combined to predict roommate compatibility.

The study uses 1,500 anonymized survey responses collected through digital forms circulated among Mumbai colleges and shared-living platforms. The dataset combines structured attributes—including age, occupation, sleep schedule, cleanliness, rent budget, and smoking habits—with lifestyle descriptions, hobbies, and self-assessments.

Research Question

Can structured lifestyle and behavioral attributes combined with textual descriptions be used to predict roommate compatibility?

The research also investigates whether personality traits can be inferred from lifestyle descriptions and subsequently used to improve compatibility classification.

Methodology

The system follows a hybrid pipeline:

Survey Data
Preprocessing
Personality Trait Prediction
Feature Integration
Compatibility Classification
Flask Deployment

Structured data was processed using missing-value imputation, one-hot encoding, and standard scaling. Textual responses were tokenized using BERT's tokenizer, with padding and truncation to 50 tokens.

Personality Trait Prediction

The system predicts the Big Five personality traits:

Agreeableness Conscientiousness Openness Extraversion Neuroticism

For textual lifestyle descriptions, Bi-LSTM and BERT were used to extract personality-related signals. Random Forest was used to infer personality traits from structured information. The resulting five-dimensional personality representation was then combined with the original input features.

Compatibility Classification

Five models were evaluated:

Model Purpose
Logistic Regression Baseline and interpretability
Random Forest Nonlinear structured-data relationships
SVM High-dimensional classification
Bi-LSTM Sequential text representation
BERT Contextual semantic representation

Random Forest was configured with 100 trees and maximum depth 5, while BERT used the bert-base-uncased architecture and [CLS] embeddings for downstream classification.

Results

Compatibility Classification

Model Accuracy Precision Recall F1
Logistic Regression 0.78 0.76 0.79 0.77
SVM 0.81 0.80 0.81 0.80
Bi-LSTM 0.83 0.82 0.83 0.82
BERT 0.84 0.83 0.84 0.83
Random Forest ★ 0.86 0.85 0.86 0.85

Random Forest achieved the highest reported F1-score for compatibility classification at 0.85, while BERT achieved 0.83.

For personality-trait prediction, the reported results included:

  • BERT — Agreeableness: F1 0.82
  • Bi-LSTM — Openness: F1 0.81
  • Random Forest — Conscientiousness: F1 0.80

Five-fold cross-validation showed relatively consistent model performance, with Random Forest ranging from 0.84–0.86 and BERT from 0.82–0.84 across the reported folds.

What the Results Suggest

The experiments show different strengths across the models.

Random Forest performed strongly on structured data and provided feature-importance information. The analysis identified variables such as budget and sleep schedule among important predictors.

BERT captured contextual information from free-text lifestyle descriptions, allowing the system to incorporate behavioral and personality-related cues that are difficult to represent through predefined categories.

This supports the use of a hybrid approach in which structured behavioral information and textual information contribute different types of signals to the compatibility prediction.

From Research to Application

The final pipeline was deployed as a Flask web application.

Users provide structured survey responses and free-text lifestyle descriptions. The system processes the input, predicts personality traits, performs compatibility classification, and returns a compatibility prediction with probability information and visual outputs.

The application also generates:

  • Feature-importance visualizations
  • Confusion matrices
  • ROC curves
  • Personality-trait summaries

The research therefore moves from data collection → model development → evaluation → deployment rather than stopping at model experimentation.

Limitations & Future Work

The study is based on self-reported survey data, and compatibility is inherently subjective and context-dependent. The 1,500-response dataset also limits the extent to which the results can be generalized to other populations.

Future work could include larger datasets, real-time learning from user feedback, longitudinal validation using actual roommate outcomes, multimodal inputs, newer transformer architectures such as RoBERTa and DeBERTa, and evaluation across additional cities and housing platforms.

Conclusion

This research developed a hybrid machine-learning framework for roommate compatibility prediction by combining structured behavioral information, personality-trait prediction, and natural-language processing.

The results demonstrate that different model architectures capture different aspects of the problem, with Random Forest performing strongly on structured data and BERT providing contextual representations of lifestyle descriptions.

The resulting Flask application demonstrates how this research can be translated into a practical compatibility-matching system for shared living environments.
